# LNU Smart Events System

This repository contains:
- A Laravel backend API and infrastructure files.
- A Flutter frontend application for smart event management.

## Project Structure

- `backend/`: Laravel backend services.
- `lib/`: Flutter application source.
- `android/`, `ios/`, `linux/`, `macos/`, `windows/`, `web/`: Flutter platform targets.

## Getting Started

## Backend (Laravel)

1. Install PHP dependencies with Composer.
2. Configure your `.env`.
3. Run migrations and start the Laravel server.

## Frontend (Flutter)

1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Start the app using `flutter run`.
